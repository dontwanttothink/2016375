## Uso de modelos de lenguaje

Algunos de nosotros usamos modelos de lenguaje para ayudarnos a entender el código de nuestros compañeros, para obtener inspiración o ideas para el juego, y para aclarar dudas sobre APIs web o de JavaScript. El código, los comentarios y la documentación fueron escritos por nosotros.
