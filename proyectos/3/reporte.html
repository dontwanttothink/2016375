Logica del juego

Partida:

Requisitos

  • Tablero
  • Personajes jugador
  • Personajes del bot
  • Dificultad
  • Comienzan todos los personajes del jugador en la primera columna y los personajes del bot en la ultima columna de la matriz
  • Se acaba la partida si todos los personajes de un equipo pierden toda su vida
  • Si el jugador pierde se despliega otra pagina con el "perdiste", boton para volver a intentar
  • Si el jugador gana todos los personaje de este avanzan a la siguiente sala, se busca el camino mas corto para ir a la salida, el personaje principal ira primero y lo seguiran los demas a medida de que el este mas adelante que ellos, avanzara para la salida, casilla por casilla
  • La vida de los personajes se regenerara completamente al pasar de nivel
  • A medida que avanzamos en los niveles, se aumenta la cantidad de personajes de ambos equipos, la energia dada para cada nivel(dependiendo de la matriz) y se mejora el algoritmo del bot

Tablero:

  • Depende de una matriz
  • Los primeros se haran a mano, a medida que se avanze de nivel se ira aumentando la matriz del tablero
  • Algunos niveles tendran obstaculos
  • Se ira cambiando de aspecto los niveles con el fin de seguir la historia base del juego
  • Esta se divide en casillas visibles para el jugador

Personaje:

Stats:

  • Vida base : int
  • Daño base : int
  • Enfriamento de la habilidad : int
  • rango : int

Interaccion

  • Al dar click en el personaje se despliegara un menu con las 4 acciones de cada personaje, al volver a darle click se retrae este menu (se necesita para esto columna y fila, para ubicar el menu)
  • Cada personaje tendra sus propias animaciones y aspecto
  • Se mostrara la barra de vida de cada personaje

Acciones:

Atacar:

  • gasta energia, tiene un daño que puede ser boosteado por abilidades futuras
  • tiene un rango medido por casillas (Se necesita un enemigo )

Mover:

    gasta energia dependiendo de cuantas casillas se mueva (se necesita la columna y fila de destino)

Bloquear:

    gasta energia, no recibe el daño del siguiente ataque

Abilidad unica:

  • Gasta toda la energia del personaje
  • se puede utilizar despues ciertos turnos(depende del personaje)
  • esta tambien tiene un rango dependiendo del personaje (Se necesita un enemigo)

Turnos:

  • Comenzara el jugador, seguido por el bot y asi sucesivamente
  • Cada jugador tiene un max de energia que se llenara por cada turno, con esta se realizaran todas las acciones
  • El turno se acaba si el jugador lo desea o si el jugador se queda sin energia

Razón por la que se usó

Usé el asistente de Kagi para hacer preguntas abiertas sobre APIs Web, de p5 y de JavaScript.

Usé a Claude Code para implementar algunos cambios más rápidamente. Por ejemplo, me ayudó a conectar la BFS que había escrito con los sistemas de ataque y movimiento del juego, cuando antes solo se usaba la BFS para reproducir la animación del movimiento.

Claude Code me ayudó también a extender la máquina de estados de interacción, y a escribir algo de código tedioso para la caja de texto.
